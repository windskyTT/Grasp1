```text
│                       │   └── keypoints.py  不是强制标准 MDP 文件。主要服务 dexterous grasping 任务。作用：定义并计算机器人上用于抓取、距离和 affordance 的关键点

│                           │   ├── student_env_cfg.py
│                           │   └── agents/
│                           │       ├── __init__.py
│                           │       └── rsl_rl_ppo_cfg.py  PPO 怎么训练这个 Teacher？

│                               ├── student_env_cfg.py
│                               └── agents/
│                                   ├── __init__.py
│                                   └── rsl_rl_ppo_cfg.py
└── logs/
```
