```text

=
q_current
+
```




```text
target clamp
```

可以采用：

```text
自定义一个轻量 RelativeJointPositionAction 子类
```

只增加：

```text

```

```text
delay
previous-target state
substep switching
```

# 8. Phase 4：明确 Reward 时间语义

## 8.1 当前问题

当前实现：

```text
weight
=
source_coeff / CONTROL_DT
```

RewardManager 再乘：

```text
step_dt
```

因为：

```text
CONTROL_DT = step_dt = 1/60
```

所以：

```text
每个 policy step
仍然得到完整 source coefficient
```

但：

```text
policy frequency:
5 → 60
```

导致：

```text
每模拟秒 reward 累计次数 ×12
```

---

## 8.2 必须先做设计决策

明确选择一种：

### Option A：保持 source per-policy-step semantics

含义：

```text
每一步 reward 系数与旧 Teacher 相同
```

当前代码基本符合。

代价：

```text
reward / simulated second 发生变化
```

### Option B：保持 source per-simulated-time semantics

含义：

```text
每模拟秒 reward 强度与旧 Teacher 接近
```

则新每步 reward 需要约缩小到：

```text
旧每步的 1/12
```

---

## 8.3 推荐先做 A/B 诊断

不要立刻拍脑袋改。

建立：

```text
reward_step_semantics

reward_time_semantics
```

两套只用于实验的配置。

同样：

```text
16 env
300 steps
相同 seed
相同 action sequence
```

比较：

```text
reward/step
reward/s
reward/episode
```

---

## 8.4 重点 Reward

重点分析：

```text
affordance_reward
arm_joint_vel_reward_
obj_qvel_reward_
obj_vel_reward_
arm_collision_reward
obj_displacement_reward
```

因为当前这些项对 total reward 贡献较大。

---

## 8.5 不要改 reward 公式

本 Phase 只处理：

```text
time scaling
```

不要修改：

```text
reward functional form
reward signs
reward contact definition
affordance formula
```

# 9. Phase 5：重新评估 PPO gamma / lambda 时间尺度

## 9.1 当前问题

当前：

```text
gamma = 0.996
lambda = 0.95
```

来自旧 Teacher 风格。

但：

```text
policy:
5 Hz → 60 Hz
```

导致同样的 gamma 代表完全不同的真实时间折扣。

---

## 9.2 先计算旧时间等效 gamma

如果旧：

```text
gamma_old = 0.996
dt_old = 0.2 s
```

新：

```text
dt_new = 1/60 s
```

保持同样 physical-time discount：

```text
gamma_new
=
gamma_old ** (dt_new / dt_old)
```

应计算并记录精确值。

不要硬编码近似值。

---

## 9.3 Lambda 同样分析

对：

```text
lambda = 0.95
```

做相同的 temporal-horizon 分析。

但注意：

```text
GAE lambda
```

与 gamma 的物理意义不完全相同。

因此：

```text
只计算候选值
不要自动替换
```

---

## 9.4 候选配置

最少比较：

```text
PPO-A:
gamma=0.996
lambda=0.95
```

和：

```text
PPO-B:
gamma=physical-time-equivalent
lambda=对应候选值
```

如果 lambda 不确定：

保留 lambda=0.95，
只先测试 gamma。

---

## 9.5 不修改其它 PPO 超参

本阶段不要修改：

```text
hidden dims
learning rate
entropy
clip
epochs
mini batches
desired KL
```

除非 100/500 iteration 证明确实有必要。
