## B. 六项优化与生命周期

### 1. 消除 affordance reward 的完整观测重算

原来 `affordance_reward()` 调用 `compute_group("policy")`，仅为读取 102:153。
现在 reward 和 observation 读取同一份 `nearest_affordance_vectors_w()` 结果。
仍按原流程执行物体系 `cdist → argmin → gather → 向量差 → 转世界系`，奖励取该世界向量的模。
没有改用其它距离公式，也没有改变采样的 200 个 affordance 点。

256 环境的 5 步 profile 中，`aten::cdist` 从 **15 次减少到 5 次**。

### 2. 静态 body/joint 索引

`TeacherObservation` 初始化时，从已加载 articulation 按名称及 `preserve_order=True`
解析 hand/arm/object 索引。手腕采用六个已解析 arm body 中的 wrist_3_link。
UR5 关节索引复用已初始化 Teacher action term 的前六个控制关节。

17 个 hand 点和 6 个 arm 点与原函数逐点比较通过；22 关节的名称/动作顺序保持不变。
运行测试把 articulation 的 `find_bodies/find_joints` 替换为报错函数，仍能完成控制步，
确认运行阶段不再解析这些名称。没有硬编码 USD body index。

### 3. 接触数据共用

每个接触组只按原传感器顺序读取/stack 一次 normal 和 friction forces，
在 filter body 维求和，再计算 total/tangential/normal 模并乘 `physics_dt`。
不同奖励复用这些 `[N,K]` 结果。arm collision 仍读取原来的 unfiltered contact-time 标志。

当前观测与奖励原本对非有限接触力有不同处理：观测逐分量 `nan_to_num`，奖励保留原始值。
缓存分别保留两种结果，没有把观测的清理规则应用到奖励。
人工 NaN/Inf 接触力测试分别对照原路径通过。

### 4. 共享几何与缓存有效期

缓存属于单个环境实例，由 observation term 初始化。
Isaac Lab 在每轮物理积分结束后、termination/reward 前递增 `common_step_counter`。
第一次读取检测到新步后丢弃上一轮动态结果。因此 reward 使用当前步的几何数据。

同一步顺序为：termination 读取当前物理状态 → reward 复用 → reset/interval 事件 → 正式 observation。
reset、首次碰撞回退和 object bias 写状态时显式失效对应 `env_ids`。
随后只重算这些环境的缓存行，未重置行继续复用。观测的腕部初始参考和 Euler 历史仍由原状态逻辑处理。

| 持久动态结果 | shape |
|---|---|
| hand 世界关键点 / hand 物体系关键点 / nearest vectors | 各 `[N,17,3]` |
| arm 世界关键点 | `[N,6,3]` |
| object top 位姿 | `[N,7]` |
| hand/object 接触 | 4 个 `[N,13]`，含观测专用 total |
| hand/table 接触 | 3 个 `[N,13]` |
| arm 接触 | 3 个 `[N,6]` |

2048 环境上述动态缓存约 **2.24 MiB**。成对距离/差值仅为临时张量，不长期保存。

### 5. 零权重 push_reward

已读取本机 Isaac Lab `RewardManager.compute()` 实现：`weight == 0.0` 时直接 `continue`，
并把该日志列置零。运行验证将 push 函数替换成报错函数，RewardManager 仍正常计算。

因此保留 push 源函数、原数学定义、零权重配置及全部 17 个日志列。
无需删除 term，TensorBoard 指标名称与数量保持不变。

### 6. Reset/startup 数据访问

最低点从 observation 已建立的 metadata 读取，消除原来每个环境重复读同一文本文件的操作。
唯一物体的名称索引在 startup 用字典建立。OBJ 和 stable `.npy` 原本就是 startup 读取，继续保持。

保留原 reset 网格的 `process=False`，在 startup 上传 float32 三角形：
训练集 35 个物体约 **0.87 MiB**，ShapeNet 30 个物体约 **6.17 MiB**。
不使用处理方式不同的 observation mesh 替代 reset mesh。
stable states 按环境顺序一次上传为 `[N,7]`，reset 直接索引对应行。

普通 reset 不再把所有选中环境 ID 搬到 CPU 以构造名称列表，也不再重复上传网格/stable state。
将 `Path.read_text/np.load/trimesh.load_mesh` 替换为报错函数后，partial reset 仍通过。
保留碰撞回退中的 CPU 名称处理和随机同行选择顺序；缺失 stable state 的错误报告可以使用 CPU。
