# Isaac Lab 项目验收与性能优化执行 Prompt

> 用途：将本文件直接提供给 Codex / Coding Agent，要求其在 **Isaac Lab 外部项目完成后自动执行验收、排错和性能检查**。  
> 目标：不是“代码能启动”即可，而是确认项目在 **工程结构、仿真、MDP、强化学习、长期稳定性和性能** 六个层面均达到可用状态。

---

## 0. 项目背景与固定约束

当前项目背景如下：

- Isaac Lab：`2.3.2`
- Isaac Sim：`5.1.0`
- 安装方式：Isaac Sim Pre-built Binaries
- GPU：NVIDIA RTX 3070 Ti
- NVIDIA Driver：580
- 项目类型：Isaac Lab External Project
- 项目创建方式：`./isaaclab.sh --new`
- 项目名称：`Grasp1`
- 工作流：`Manager-based single-agent RL`
- 主要 RL 框架：`RSL-RL`
- 主要算法：`PPO`
- 默认在当前代码目录执行命令
- 使用项目当前已经配置好的 Conda 环境 :grasp
- 不要擅自创建新的 Conda 环境
- 不要修改 Isaac Lab 官方源码，除非用户明确要求
- 优先修改 `Grasp1` 外部项目中的代码
- Runtime MDP 计算优先使用 PyTorch/GPU tensor
- 不要为了让测试通过而删除核心功能、注释核心逻辑或降低任务定义正确性

# 11. Gate 8：Reward 验收

必须逐个验证 reward term。

不要只看：

```text
total_reward
```

至少检查当前任务中存在的：

```text
reach
contact
grasp
lift
success
action penalty
joint velocity penalty
other regularization
```

对每一个 Reward Term：

1. 检查输出 shape；
2. 检查 dtype/device；
3. 检查 finite；
4. 检查符号；
5. 检查数量级；
6. 检查物理语义；
7. 检查 weight 后的贡献。

必须排查：

```text
奖励方向写反
惩罚比主奖励大几个数量级
reward 永远为 0
reward 永远为常数
reward 只有极少数 unreachable 条件才出现
单位错误
```

人工构造或利用场景状态检查：

```text
远离 object → reaching reward 应低
靠近 object → reaching reward 应提高
成功 grasp → grasp reward 应提高
达到 lift height → lift/success reward 应触发
```

如果某 reward 的设计正确但数值比例明显失衡，记录后再调整。

不要为了让 PPO reward 上升就删除失败惩罚或直接增大 success reward。

# 21. 首要性能优化项

## 21.1 Headless

正式训练必须优先：

```text
headless
```

除非任务必须渲染。

## 21.2 关闭不必要 Rendering

如果 Teacher policy 只使用：

```text
joint state
object pose
privileged state
```

不要开启不需要的 RGB/Depth Camera。

## 21.3 避免 CPU ↔ GPU 同步

重点搜索：

```bash
grep -R "\.cpu()" -n source scripts
grep -R "\.numpy()" -n source scripts
grep -R "\.item()" -n source scripts
```

不要机械删除所有 `.item()`。

重点判断：

```text
是否位于每个 environment step 的高频路径
```

如果是，尽量消除。

## 21.4 避免 step 中 print

搜索：

```bash
grep -R "print(" -n source
```

如果 print 位于高频：

```text
observation
reward
action
reset
step
```

路径，改为：

```text
Debug flag
低频 logging
一次性 startup log
```

## 21.5 避免 Python env loop

搜索类似：

```text
for ... in range(num_envs)
for env_id in ...
```

如果位于 runtime step，改为：

```text
torch vectorized operation
env_ids tensor indexing
```

## 21.6 固定索引只解析一次

以下内容不要每 step 重新解析：

```text
joint names
joint ids
body names
body ids
regex
object index mapping
```

初始化阶段 resolve。

Runtime 使用：

```python
tensor[:, joint_ids]
```

# 24. Physics 性能检查

检查：

```text
sim dt
decimation
solver position iterations
solver velocity iterations
substeps
contact settings
```

目标是：

```text
找到满足稳定性的最低计算成本
```

不能仅为了 FPS 随意降低。

注意：

```text
control_dt = sim_dt × decimation
```

改变 decimation 会改变控制频率。

必须确认没有破坏抓取控制逻辑。
