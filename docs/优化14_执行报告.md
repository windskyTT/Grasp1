### 4. PhysX 接触映射、单位与时间缩放

`mdp/observations.py:635–723` 的 `TeacherRewardState` 保留13个源手部接触槽、6个机械臂槽和4个机械臂全接触标志。手部槽顺序为 `wrist_3_link`，随后各指的 `link_1/2/3`、`link_5/6/7`、`link_9/10/11`、`link_13/14/15`；USD 名称中的点替换为下划线。独立 `link_3/7/11/15_0_tip` 回归 distal 槽 `3/6/9/12`，对应源 RaiSim 固定 tip 合并刚体的语义。源 `std::map::operator[]` 未显式映射的刚体归槽0的行为也被保留。

使用现有 ContactSensor 及 PhysX rigid contact view 的真实数据，按环境分别过滤 `Object/top`、`Object/bottom`、`Table`。Affordance 取 `top`，Table 取桌面，Arm 按源规则合成对应碰撞对象的向量；四项机械臂全接触标志读取真实 contact count，而不是判断合力是否非零。

冲量计算为：

```text
J_world = (F_normal_world + ΣF_friction_patch_world) × physics_dt
physics_dt = 1/120 s
```

先对同一源槽内的刚体／摩擦 patch／碰撞对进行向量求和，再求模；Affordance 冲量奖励只取世界 XY，Table/Arm 使用三维冲量。这里的 XY 不是“摩擦方向”。读取末物理子步的接触，不把两个子步的冲量再次累加，不乘 `control_dt`，也不重复做力到冲量换算。

原始奖励的时间适配为：

```text
r_teacher_step = Σ(raw_teacher_term × source_coeff / 0.2) × step_dt
step_dt = control_dt = 1/60 s
r_teacher_step = Σ(raw_teacher_term × source_coeff) / 12
```

这保持单位物理时间的源系数强度，不表示当前每步奖励与源 `0.2 s` 每步奖励相同。DexSuite 两项保持官方每秒权重，直接由 RewardManager 乘 `step_dt`；成功奖金单独抵消该乘法。`train.py` 记录分项奖励时将 `_step_reward` 乘一次 `step_dt`，因为 RewardManager 的该统计字段本身已经除过 `dt`。

**ADAPTED：** RaiSim 的逐接触点完整冲量与 PhysX 分开报告的 normal contact／friction patch 不能逐点一一对应，源 `|J| < 0.001 N·s` 的逐点过滤未严格复现。当前保留真实刚体合冲量，不添加替代阈值，不对合冲量使用该过滤冒充逐点过滤。其他源接触阈值和裁剪规则保留，但接触数值不能宣称与 RaiSim 完全相同。
