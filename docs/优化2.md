## 8. Phase 4：Action

### 修改为 Relative Joint Position

Teacher-v0 改用：

```text
RelativeJointPositionActionCfg
```

一个 ActionTerm 联合控制：

```text
UR5 6 + Allegro 16 = 22
```

不要拆成 arm/hand 两个 policy action。

### Joint order

显式保持：

```text
UR5_JOINT_NAMES + ALLEGRO_JOINT_NAMES
```

初始化使用 `preserve_order=True`，runtime 不重新 `find_joints()`。

### Action scale

第一轮先保留当前近似幅度：

```text
UR5 = 0.005
Allegro = 0.015
```

先隔离 Action class 改动。

之后再单独测试 Dexsuite 风格 `scale=0.1`。

若测试 0.1，记录：

- joint target delta
- joint clipping rate
- joint velocity
- joint effort
- contact impulse
- termination rate

如果过激，继续使用 Relative Action，但采用 per-joint scale dictionary。

### 删除 action delay

Teacher-v0 不再使用：

```text
delay_probability
delay_sim_steps
previous target delay
```

### Observation 22:44

Relative Action 下：

```text
processed_action = Δq
q_target = q + Δq
q_target - q = Δq
```

所以 Observation 22:44 应为：

```python
target_error = processed_actions
```

或数学等价实现。

禁止：

```python
processed_actions - joint_pos
```

### Phase 4 专项测试

- all-zero action
- 仅 action[0] 非零 → UR5 joint 0
- 仅 action[6] 非零 → 第一个 Allegro joint
- 全 22 joint 顺序检查
