# 2. 当前未解决问题

## 2.1 `clip_actions = null`

当前 RSL-RL 参数：

```text
clip_actions = null
```

所以 Gaussian policy 输出没有 wrapper-level `[-1,1]` clipping。

但 Optimization-3 的 action scale 选择是基于：

```text
uniform[-1,1]
```

random action benchmark。

这意味着：

```text
random benchmark动作分布
!=
trained policy动作分布
```
