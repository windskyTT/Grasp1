# 8. UR5-Allegro 的目标安装方式

UR5-Allegro 必须安装到黑色 Table 的**靠近机器人侧的桌边**。

参考 `Isaac-Lift-Cube-Franka-v0`：

```text
Robot base
   ↓

   O ───────────────→ 工作方向
   │
┌──┴─────────────────────────┐
│                            │
│           Table            │
│                     Object │
│                            │
└────────────────────────────┘
```

机器人不能：

```text
站在桌子外面的白色区域
悬空
完全放在桌子中央
位于物体工作区域中央
```

目标是：

```text
机器人底座位于桌子近侧边缘
机器人主要工作空间位于桌面内部
机械臂朝向 object workspace
```

---

# 9. 不要直接复制 Franka 的绝对坐标

不要简单写：

```python
robot.pos = (0.0, 0.0, 0.0)
```

并声称已经和 Franka 一致。

原因：

```text
Franka 官方 Table 的几何形状
≠
当前 Grasp1 黑色 Cuboid Table
```

因此这里要求一致的是：

```text
Robot 与 Table 的相对安装关系
```

而不是机械复制绝对 world coordinate。

# 10. 自动确定 UR5 的 X/Y 安装位置

首先确定：

```text
table_min_x
table_max_x
table_center_y
```

UR5 当前主要工作区域位于桌子 +X 方向时，应将机器人放到：

```text
Table 的 min-X 一侧
```

机器人 Y 方向优先与桌子中心线对齐：

```python
robot_y = table_center_y
```

机器人 X 必须根据 UR5 base 实际 footprint 决定。

检查 UR5 USD 中 base_link 的：

```text
visual bounds
collision bounds
```

确定机器人底座在 XY 平面上的最大有效半径：

```text
base_radius
```

目标：

```python
robot_x = table_min_x + base_radius + safety_margin
```

其中：

```text
safety_margin ≈ 0.01 ~ 0.02 m
```

要求：

```text
整个 UR5 base footprint 都位于黑色桌面上
但机器人尽量靠近桌边
```

不要随意猜一个 X 数值。

必须根据实际 base geometry/collision bounds 确定。

# 11. 确定 UR5 的 Z

删除 Mat 后，机器人直接放在：

```text
黑色 Table 顶面
```

计算：

```text
table_top_z
```

然后检查 UR5 USD 的：

```text
base_link origin
```

相对于实际安装底面的 Z offset。

如果：

```text
base_link origin == mounting plane
```

则：

```python
robot_z = table_top_z
```

如果 base_link origin 与 mounting plane 有 offset：

```text
base_mount_offset_z
```

则：

```python
robot_z = table_top_z - base_mount_offset_z
```

必须通过实际 USD geometry/collision bounds 验证。

禁止通过增加：

```text
Mat
WoodenTable
Pedestal
额外 Cuboid
```

来解决 Z offset。

# 12. UR5 朝向

目标是：

```text
UR5 工作方向朝向桌面内部
```

如果当前 UR5 在：

```python
rot=(1, 0, 0, 0)
```

时已经朝向桌面内部，则保持不变。

不要为了“和 Franka 一样”无意义地旋转机器人。

只有当 UR5 当前 forward/workspace direction 明显背离桌面时，才修改 root yaw。

需要修改时：

1. 明确当前 UR5 base frame 的 +X/+Y；
2. 明确机械臂工作区朝向；
3. 选择使机械臂朝向 Table center 的 yaw；
4. 在最终报告中输出 yaw。

不要再使用：


```text

```
